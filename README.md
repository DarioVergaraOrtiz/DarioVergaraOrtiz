### API de Facturación Electrónica SRI

Microservicio REST para automatizar el ciclo de facturación electrónica en Ecuador, incluyendo generación de XML, firma digital, envío y autorización de comprobantes mediante los servicios del SRI.

Incluye firma XAdES-BES, generación de RIDE, control de secuenciales, integración SOAP y protección de endpoints.

**Tecnologías:** Node.js · Express · MariaDB · SOAP · XML · XAdES-BES

**Tecnologías:** Java · Quarkus · PostgreSQL · Vue.js · REST APIs
